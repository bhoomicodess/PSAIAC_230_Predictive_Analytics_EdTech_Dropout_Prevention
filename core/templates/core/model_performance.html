Why Logistic Regression is the current project-selected model

Logistic Regression is the current project-selected model because it achieved the highest measured accuracy and ROC-AUC among the evaluated models in the current experiment. These results are based on the current held-out evaluation dataset and may differ when the model is applied to data from another institution or learner population.
