# Screenshot Checklist

No screenshots were captured or added as part of this documentation update. Capture each image directly from the running application after signing in with approved demo accounts. Do not fabricate screens, alter displayed metrics, or expose real learner information.

## Recommended Screens

- [ ] **Login** - `/login/`; show the real login form without entering credentials in the capture.
- [ ] **Dashboard** - `/`; show the current summary state. Prefer a demo database with synthetic learner data.
- [ ] **Student Risk Dashboard** - `/student-risk-dashboard/`; show risk counts, filters, and a redacted/synthetic learner row.
- [ ] **Individual Prediction** - `/individual-prediction/`; show probability, risk band, and model indicators for a synthetic learner.
- [ ] **Recommendations** - `/recommendations/`; show the actual rule-based support suggestions.
- [ ] **Intervention Management** - `/interventions/`; show statuses, follow-up dates, and the current filter controls.
- [ ] **Model Performance** - `/model-performance/`; show actual experiment metrics, ROC view, and threshold diagnostics.
- [ ] **Reports** - `/reports/`; show current aggregate summaries and export control.
- [ ] **Batch Prediction** - `/batch-prediction/`; show a demo upload/result and remove any personal data from the source file.
- [ ] **Settings** - `/settings/`; show the current informational settings page, without secrets or account details.

## Capture and Review

- [ ] Confirm screen content came from the running project, not a mockup.

- [ ] Use synthetic IDs and remove names, emails, credentials, tokens, host secrets, and personally identifying information.
- [ ] Capture `/` only under the intended Admin/Educator workflow; verify a Student is redirected to the own learner profile and does not receive institutional aggregate content.
